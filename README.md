# IVAS SMS API

Automatically fetch phone numbers and OTP messages from IVAS portal.

## 🚀 Quick Deploy

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy)

## 📦 Installation

```bash
git clone https://github.com/YOUR_USERNAME/ivas-sms-api.git
cd ivas-sms-api
npm install
cp .env.example .env
# Edit .env with your cookies
npm start
